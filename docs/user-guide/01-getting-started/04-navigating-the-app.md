# Navigating the app

*One sidebar. Income on one side, expenses on the other, tax tools and settings underneath.*

<!-- screenshot: the full sidebar, desktop width -->

## Home and New

**Home** is the front door: recent activity and the two overviews.

**New** is the everyday pair of actions:

- **Send Invoice** opens a new outgoing document.
- **Add Expense** opens the upload page.

## Income

| Item | What it is |
|---|---|
| **Overview** | Money coming in. |
| **Documents** | Every document you have drafted or issued. |
| **Collections** | Who has not paid yet. |
| **Clients** | The customer directory those documents are addressed to. |

Projects, when you bill milestones, sit further down the sidebar.

## Expenses

| Item | What it is |
|---|---|
| **Overview** | Money going out. |
| **Invoices** | Supplier invoices you have kept. |
| **Pending** | Extractions waiting for you to approve or reject. |
| **Duplicates** | Uploads that look like something already on file. |
| **Vendors** | The suppliers those invoices came from. |

## Taxes

| Item | What it is |
|---|---|
| **VAT estimates** | A working estimate from the records in this account, not a filing. |
| **Uniform Structure** | The Tax Authority's export format for your accountant. |
| **Hashavshevet** | Export toward the bookkeeping software of that name. |
| **ITA** | The one-time connection to the Tax Authority. Administrators only. |

## Settings and help

**Settings** holds business details, the PDF template (logo and colors), API keys, billing, team, and security.

**Developers** opens the API reference. That reference is the only write-up of endpoints — this guide does not copy it. See [API, webhooks, and MCP](../08-integrations-api/01-api-and-webhooks.md).

**Tutorials** inside the app are short walkthroughs. This user guide is the full version, and both point at the same product.
