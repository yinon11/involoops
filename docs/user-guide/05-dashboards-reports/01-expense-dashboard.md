# Dashboards

*Overviews read approved expenses and issued documents. Pending uploads are not in the totals yet.*

<!-- screenshot: the expense overview -->

## Money out

**Expenses → Overview** sums the supplier invoices you approved. Rejected and still-pending uploads are not in that total. Open **Pending** if a bill seems missing.

## Money in

**Income → Overview** follows the documents you issued. Drafts are not sales yet.

## Profit

The profit view puts issued income next to approved expenses so you can see the gap. It uses the same records as the two overviews. It is not a formal profit-and-loss statement for filing.

## Currency

Amounts are stored in the currency of each document. The dashboard can show a display currency; the conversion is for reading the screen, and the document itself keeps the original currency. Foreign-currency tax invoices follow the rules on the issue form, not the dashboard toggle.

## VAT estimates

**Taxes → VAT estimates** is the in-app estimate from those same records. Treat it as a check before you talk to your accountant, not as the report you file.
